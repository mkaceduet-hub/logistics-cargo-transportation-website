# CargoFlow — Logistics & Cargo Transportation Website

A modern, responsive logistics company website concept built with HTML, CSS and vanilla JavaScript. CargoFlow presents freight transportation, air and sea cargo, warehousing and project logistics through a clean, professional interface.

## Live Demo

After enabling GitHub Pages, your site will be available at:

`https://mkaceduet-hub.github.io/logistics-cargo-transportation-website/`

## Features

- Responsive layout for desktop, tablet and mobile
- Modern logistics-inspired hero and service sections
- Road freight, air and sea cargo, warehousing and project logistics cards
- Company introduction and service highlights
- Sample shipment-reference lookup interaction
- Quote request form with client-side validation and feedback
- Mobile navigation menu
- Semantic HTML and accessible form labels
- External photography and Google Fonts

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No build tools or package installation are required.

## GitHub Pages Deployment

1. Open the repository's **Settings** tab.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`.
5. Click **Save** and wait for GitHub Pages to publish the site.

## Demo Limitations

This is a front-end portfolio demonstration. The shipment lookup does not connect to a carrier or tracking database. The quote form validates and displays an on-page confirmation only; it does not send, store or process submissions. The email, phone number, company details and service information are illustrative and should be replaced with verified business information before production use.
